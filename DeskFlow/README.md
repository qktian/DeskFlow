# DeskFlow

轻量纯净的 Windows 桌面整理工具，包含盒子分组、自动归类、待办清单、番茄钟与托盘常驻。

## 1.2.0 番茄钟统计

番茄钟新增「统计」页：按今天、近 7 天、近 30 天或自定义日期查看时长、番茄数、完成率、中断次数、每日趋势、事项占比、今日目标和连续专注天数。支持导出当前范围的统计 CSV，已有历史直接参与统计。详见 [统计说明](docs/番茄钟统计.md)。

## 1.1.0 番茄钟集成

托盘、软件设置及待办右键菜单均可打开番茄钟。支持专注/长短休息、暂停继续、自动循环、事项关联、每日目标、历史导出、精简面板、置顶、声音与通知。退出和锁屏时暂停并保存；重新打开可继续。

使用编译好的 `publish/DeskFlow.exe`，包含 Windows x64 运行时。升级前请先退出旧程序，配置继续沿用。规则和验证范围见 [番茄钟说明](docs/番茄钟.md)。

## 2026-10-04 稳定性与性能优化

- 修复部分旧程序快捷方式的图标过小：识别过量透明留白，保持比例缩放；修复透明边缘与混合 DPI 图标缓存。
- 重命名限制为文件名，拒绝路径及 Windows 保留名称；保留手动归属与排除记录，删除失败保留条目。
- 配置使用临时文件落盘后原子替换，保护有效备份；相同内容不重复写入，保存失败显示提示。
- 新增自定义规则优先于已有规则；批量分类只排序一次规则，批量拖入只刷新/保存一次。
- 日常文件事件仅处理变化路径、刷新受影响盒子；监听溢出时重新扫描，连续写入不再无限推迟刷新。
- 待办每分钟刷新时间状态，显示器变化时回收越界待办；设置窗口取消或关闭时回滚并持久化。
- 修复大写字母热键隐含 Shift，以及后台隐藏系统图标与显示/退出的竞争。

完整检查结果与后续计划见 [项目检查与优化计划](docs/项目检查与优化计划.md)。

### P2 优化

大量条目按行虚拟化并仅为可见条目提取图标；全量扫描转入后台，元数据与图标缓存设有容量限制。规则支持排序、关键词编辑、归类预览和命中解释；Ctrl/Shift 可批量选择，整理可在当前会话撤销。托盘提供已收纳条目离线搜索，快照可恢复现存盒子及待办面板的布局。性能数据及边界见 [P2 验收](docs/P2-性能归类搜索与快照.md)。

### 面板对齐修复

- 文件盒子与待办面板共用拖动/缩放吸附，两个吸附开关同时作用于两类面板。
- 待办自动高度保持顶部锚点，内容放不下时滚动，不再强制改为屏幕上边缘 12px。
- 屏幕回收不再额外增加 4px 边距，已经可见的坐标不变；折叠面板按标题栏高度处理。
- 缩放只改变正在拖动的方向；使用手势起点和鼠标绝对位移，吸附后可稳定拖开。
- 鼠标松开不再执行另一套屏幕吸附，避免刚对齐又跳位；自动高度计算在拖动期间暂停。

对齐是拖动/缩放时的辅助，不会把面板绑定成永久联动分组。待办开启高度自适应时顶部固定、底部随内容变化；需要固定上下边界时可关闭「高度自适应」。

### 待办完成提示

待办从未完成标记为完成时，会在面板附近播放约 2 秒的 “MISSION COMPLETED” 动画和提示音。普通任务的完成圈、右键菜单、编辑窗口，以及循环任务的完成圈和日历打卡均可触发；取消完成不会播放。

默认音效是发布目录中的 `Sounds/mission-completed.wav`，可直接用自己的 WAV 文件覆盖。也可以把 MP3 文件放在同一目录并命名为 `mission-completed.mp3`，程序会优先播放 MP3。每次完成任务时重新读取文件；删除这两个文件则只播放动画。

## 技术栈

- .NET 8（`net8.0-windows`）、C#、WPF + MVVM
- 不注入 `explorer.exe`、不移动用户文件，系统桌面图标通过 `WM_COMMAND(0x7402)` 可逆隐藏

## 工程结构

| 项目 | 职责 |
|---|---|
| `DeskFlow.Core` | 数据模型（Box / Rule / FileItem / AppConfig）、配置读写、规则引擎、桌面扫描 |
| `DeskFlow.Shell` | Win32 封装：图标提取、桌面图标收编、全局热键、屏幕与 DPI、亚克力效果、文件操作 |
| `DeskFlow.App` | WPF 表现层：盒子窗口、设置中心、托盘控制器、桌面监听、应用编排 |

## 构建与运行

```bash
# 构建
dotnet build DeskFlow.sln -c Release

# 运行
dotnet run --project DeskFlow.App -c Release

# 发布单文件夹（含运行时自包含，约 70MB）
dotnet publish DeskFlow.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true

# 发布依赖框架版本（需本机已装 .NET 8 桌面运行时，约 1MB）
dotnet publish DeskFlow.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

> 若本机未在 PATH 中安装 dotnet，使用隔离目录的 SDK：
> `C:\Users\Admin\.workbuddy\binaries\dotnet\dotnet.exe`

## V1.0 已实现功能

- **盒子**：新建 / 拖动 / 八向缩放 / 折叠 / 置顶 / 删除（删除容器不删文件）
- **样式**：背景色、文字色、不透明度、圆角、显示标题、排序方式（名称 / 类型 / 时间 / 大小）
- **归类**：8 类内置规则（文件夹 / 快捷方式 / 文档 / 图片 / 视频 / 音乐 / 压缩包 / 安装包）+ 未分类兜底；自定义规则（扩展名 / 类型，新添加的规则优先）
- **一键整理**、**新文件实时自动归类**
- **手动优先**：手动拖入的条目不会被自动归类覆盖（可开启强制归类）
- **双击桌面空白处**隐藏 / 显示全部盒子
- **贴近屏幕边缘自动卷起**，鼠标移入自动展开
- **拖拽**：文件拖入盒子、盒子之间拖移、拖出到外部窗口
- **条目操作**：打开、在资源管理器中显示、复制路径、重命名、移出盒子、删除到回收站
- **移出盒子**：移出的条目进入「已排除条目」，自动归类不会再把它收回任何盒子；设置中心「已排除条目」页可单个或全部恢复，文件被删除后记录自动清除
- **系统**：托盘常驻、开机自启、全局热键、多显示器、高 DPI、配置本地 JSON 持久化（含自动备份）
- **系统可靠性**：桌面显隐超时、独立异常恢复进程、滚动日志、热键冲突提示；详见 [P1 实现与验收](docs/P1-系统可靠性.md)
- **待办清单**：普通/循环任务、子任务、优先级、截止时间、日历打卡、历史与归档
- **归属与布局快照**：保存并恢复文件归属、手动标记、排除列表及现存盒子/待办面板布局

## 数据与配置

- 配置文件：`%AppData%\DeskFlow\config.json`（每次保存前自动备份为 `config.bak.json`）
- 设置中心「关于 → 打开配置目录」可直接查看
- 日志：`%AppData%\DeskFlow\logs`，也可从托盘「打开诊断日志」进入
- 恢复图标：托盘「恢复系统桌面图标」或运行 `DeskFlow.exe --recover-desktop`

## 已知限制（V1.0）

1. **Folder Portal（文件夹门户）**：数据模型已支持，UI 与同步逻辑在 V1.1
2. **搜索范围**：当前只搜索已收纳条目，未收纳文件和其他磁盘目录不纳入索引
3. **时钟 / 便签**、**私密盒**、**动态壁纸**、**AI 助手**：尚未实现
4. **混合 DPI 多屏**：已做 PerMonitorV2 + 逐屏缩放换算，但不同缩放率拼接处的坐标仍可能有偏差
5. **原生 Shell 右键菜单**：V1.0 使用自研菜单，未调用 `IContextMenu`
6. **亚克力背景**：在 WPF 分层窗口上会渲染为纯黑不透明，V1.0 已移除该实现；`General.UseAcrylic` 字段保留仅为兼容旧配置，启动时强制置为 `false`

## 使用提示

- 首次启动会自动在**主屏右侧**排布默认盒子
- 右键盒子标题栏 → 更多操作；右键条目 → 文件操作
- 托盘图标：左键切换盒子显示，双击打开设置，右键菜单退出
- 设置中心的盒子增删即时生效；常规设置点击保存后应用。点「取消」或关闭窗口会回滚盒子、规则、排除列表与常规设置，并写回配置；手动快照的创建/删除为独立操作。
- 卸载 / 退出后系统桌面图标自动恢复，桌面文件位置始终不变
