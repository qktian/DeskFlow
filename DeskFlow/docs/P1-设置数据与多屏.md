# P1 设置、数据与多屏

日期：2026-10-04。完成优化计划中 P1 的设置/数据和多屏实现。本轮按要求没有运行回归测试；真实混合 DPI 多屏也没有连接，因此本地发布不等于实屏验收。

## 设置草稿和并发变化

设置窗口现在编辑一份独立草稿。点击保存时，以打开设置时的基线、用户草稿和最新运行配置进行三方合并：只提交草稿中相对基线确实改变的常规字段、盒子属性、规则、快照、排除路径和快照条目归属。取消关闭不需向运行配置回滚，因此期间新增的桌面文件、拖动窗口和其他盒子变化仍保留。

显式恢复图标、保存/删除快照、重置设置等操作按原先设计当场生效。整理和重新排布会先提交当前草稿再执行。

## 配置版本与备份恢复

配置版本升到 v2。旧配置在首次启动时迁移窗口坐标，并将版本随正常配置保存。设置的「关于」页新增「从备份恢复」：确认前显示备份版本和基本数量；当前配置先复制到 `config.before-restore-*`，再从已验证备份恢复。

配置文档没有可用或已损坏的备份时不会替换现有主配置；恢复失败会给出错误。应用备份时，盒子和待办窗口会从恢复后的模型重新创建。

## 历史与快照容量

- 快照最多 100 份或合计 32 MiB。新快照超出任一限制时，按创建时间删除最旧的快照，并显示清理数量；唯一一份快照即使超过字节上限也会保留。
- 设置的维护区域可由用户确认清理一年以前已完成/已归档的待办，以及活动循环任务的一年以前打卡。先显示各项数量，活动任务本身不删除；保存失败不会显示成功提示。

## 多屏坐标和 DPI

盒子和待办模型保存屏幕设备标识及相对该屏工作区的局部坐标，不再把不同缩放屏幕的绝对像素原点分别除以本屏比例。打开窗口时按屏幕标识恢复；热插拔后若该设备消失，窗口回收到设置中选择的首选屏幕并约束在工作区内。新建盒子、待办和自动排布优先使用该屏。

设置的首选屏幕下拉显示设备标识、物理分辨率、缩放率和主屏标记。现有 PerMonitorV2 manifest 保留；WPF/WinForms analyzer WFAC010 仍会报告，因为本轮没有实机数据来判断更改 manifest 的影响。

Release 构建成功，保留一条既有 WFAC010 DPI 混合框架警告。由于环境没有完成真实混合 DPI、负坐标屏、拔插屏幕的手工验证，也没有运行回归测试，这些路径仍需实机验收。
