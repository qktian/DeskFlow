# 番茄钟统计（1.2.0）

入口：打开番茄钟面板 →「统计」。精简面板先点「展开」。旧版本的历史记录会自动参与计算，无需重新开始积累。

## 可查看的数据

- **时间范围**：今天、最近 7 天、最近 30 天、自定义日期。自定义范围包含起止当天，单次最多 366 天，不可选择未来日期。
- **概览**：专注总时长、完成番茄数、完成率、中断次数、有记录的天数及日均时长。
- **每日趋势**：可切换专注分钟和完成番茄数。分钟图中绿色为完成专注时间，红色为中断前已用时间。空白日期按 0 展示，横向滚动可查看长时间范围；悬停或点击查看当天详情。
- **事项分布**：按专注总时长排序，显示每个事项的时长、占比、完成数和中断数。待办重命名前后的记录按任务 ID 合并，名称取所选范围内最近一次记录；不同自由专注名称分开统计。
- **今日目标**：显示今天已完成数量、目标和剩余数量，无论上方选择哪个日期范围，这里始终表示今天。
- **连续专注**：每天至少完整完成一个番茄。今天尚未完成时，当前连续天数允许延续到昨天；历史最长连续天数统计全部历史，不受上方日期范围影响。
- **统计导出**：导出当前范围的汇总、每日数据和全部事项分布为 UTF-8 CSV。原「记录」页仍可导出逐次记录。

## 统计口径

1. 只统计已结束并保存的专注，当前正在运行或暂停的这一段在结束后计入。
2. 时长 = 完成专注时间 + 中断前实际已用时间。休息、暂停和离线时间不计入。
3. 完成率 = 完成次数 ÷（完成次数 + 已记录的中断次数）；没有记录时显示「—」。
4. 日均时长以所选范围内全部自然日为分母，包含没有记录的日期。
5. 跨午夜的专注归属其结束日期，日期使用电脑本地时区。统计规则与原记录页一致。
6. 今日目标使用当前设置，不将当前目标反推为过去日期的目标。

## 验证

32 项自动检查通过（原有计时 20 项，新增统计 12 项），覆盖空数据、日期边界、本地时区、任务改名、时长占比、连续天数、范围校验及 CSV 转义。
